Employee Management System

A Flask-based web application for managing employee records.

Features
- Login & Authentication
- Employee CRUD
- Photo Upload
- Search
- Pagination
- Audit Logs
- Excel Export

Tech Stack
- Python
- Flask
- SQLAlchemy
- SQLite
- Bootstrap
